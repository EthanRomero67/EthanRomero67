Packet Tracer, LAN Networking Project

This project involved designing and configuring a full-scale network topology for a healthcare organization. The work required interpreting a detailed requirements document and implementing every component using the networking concepts covered throughout the course.

← Back to Home

Project Overview

I designed a multi‑network environment for a simulated healthcare company. The topology supported both wired and wireless clients with full end‑to‑end connectivity.

What I Built

I created a multi‑subnet topology using routers, switches, a wireless router, and a cable modem. Every device was correctly connected, configured, and tested across the entire network.

Tech Used

I worked with Cisco Packet Tracer, Cisco IOS CLI, and tools like Simulation Mode. The project used Ethernet LANs, wireless networking, serial links, DHCP, ARP, ICMP, and static addressing.

What I Learned

I strengthened my understanding of IP planning, subnetting, and device communication. I also improved my troubleshooting skills using Packet Tracer’s diagnostic tools.
