Lab 5 – Comparison Website

This lab focuses on creating a two‑column comparison layout inspired by classic video game character selection screens. The goal is to use semantic HTML and Flexbox to build a clean, organized comparison page.

← Back to Home

Overview

In this lab, I planned and built a comparison webpage featuring two competing items. The layout includes headings, images, lists, and semantic HTML elements arranged in a structured design.

What I Built

I created a two‑column comparison section using Flexbox. Each item has its own image, title, description, and list of traits, all displayed side‑by‑side in a clean and balanced layout.

Tech Used

This lab uses semantic HTML elements such as header, main, article, section, and figure which was all done in visual studio code. Flexbox is used to align the comparison items horizontally with proper spacing.

What I Learned

I learned how to plan a webpage layout, structure content using semantic HTML, and apply Flexbox for responsive alignment. I also implemented a sticky header using CSS positioning.
