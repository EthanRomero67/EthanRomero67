Packet Tracer, LAN Networking Project

This project involved designing and configuring a full-scale network topology for a healthcare organization. The work required interpreting a detailed requirements document and implementing every component using the networking concepts covered throughout the course.

Project Overview

I designed a multi‑network environment that included routers, switches, a wireless router, a cable modem, and multiple end devices. The topology supported both wired and wireless clients, inter‑router communication, and access to simulated internet services. Every device was connected using the correct cable type, configured with the proper addressing, and tested for full end‑to‑end connectivity.

What I Built

I created a multi‑network topology that included routers, switches, a wireless router, a cable modem, and several end devices. The design supported both wired and wireless communication across different subnets. Every device was connected with the correct cable type and configured for full end‑to‑end connectivity.

Tech Used

Software & Tools: Cisco Packet Tracer, Cisco IOS CLI, Simulation Mode, Physical Mode Networking Technologies: Ethernet LANs, Wireless LAN, Serial WAN links, DHCP, ARP, ICMP, HTTP, static addressing Hardware (Simulated): Cisco routers, Cisco switch, wireless router, cable modem, cloud device, PCs, server, configuration terminal, straight‑through/crossover/console/serial/coaxial cables

What I Learned

This project helped me understand how devices communicate on a network, how to plan IP ranges, and how to troubleshoot connection issues using Packet Tracer tools.
